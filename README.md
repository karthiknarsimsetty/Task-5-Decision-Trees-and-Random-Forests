# Task 5: Decision Trees and Random Forests

## Objective
Learn tree-based machine learning models for classification using Decision Trees and Random Forests.

## Dataset
Heart Disease Dataset (heart.csv)

## Tools Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Steps Performed
1. Loaded and explored the dataset.
2. Split data into training and testing sets.
3. Trained a Decision Tree Classifier.
4. Visualized the Decision Tree.
5. Analyzed overfitting by controlling tree depth.
6. Trained a Random Forest Classifier.
7. Compared Decision Tree and Random Forest accuracy.
8. Evaluated feature importance.
9. Performed 5-fold cross-validation.

## Results
- Decision Tree achieved high classification accuracy.
- Random Forest provided improved generalization.
- Feature importance highlighted the most influential attributes.
- Cross-validation confirmed model reliability.

## Conclusion
Decision Trees are easy to interpret but may overfit. Random Forest reduces overfitting using ensemble learning and generally provides better performance.
